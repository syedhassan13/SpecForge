# Fact-check of paper/sections/related.tex

Checked against arXiv abstracts and arXiv HTML full texts (fetched in this session). VERINA numbers were skipped as instructed. Venue claims could not be confirmed (DBLP blocked, Semantic Scholar rate-limited); no venue is stated in related.tex itself except "ICSE 2025" in the task description for Wang et al.

Verdicts: correct / wrong / unverifiable. "Partly" means the sentence is defensible but misleading.

## Other notes

- "All of these benchmarks use one verification language": consistent with the sources (VERINA, CLEVER Lean; DafnyBench, MBPP-DFY, Clover Dafny).
- The AlphaVerus, AutoVerus, SAFE etc. paragraph ends with "none runs the same loop in two specification languages". True for the listed systems, but Shefer et al. (next paragraph) do run a verifier loop across three languages, so the novelty claim should rest on the tests-vs-verifier comparison and the probe-checked equivalent specifications.
- DafnyBench's reported figures use up to 10 attempts with verifier feedback; the text says "with verifier error messages", which is accurate.
